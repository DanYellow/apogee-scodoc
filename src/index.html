Comment ça marche ?

  • Le but de ce logiciel est de permettre de générer un tableur plus simple à importer pour la macro Excel pour Apogée.

    Le logiciel utilise un export Scodoc du semestre ainsi que l'extraction de la cohorte généré par Apogée au format texte (.txt) dans votre dossier TEMP.

    Ainsi sont supprimées toutes les colonnes inutiles pour ne garder que celles correspondant à la moyenne de chaque UE.

    Il ne vous restera ensuite qu'à copier le contenu du fichier généré et le coller dans le fichier Excel de la macro Apogée.

    • Note 1 : Ce logiciel est agnostique, il fonctionne de la même manière quelque soit le semestre, le parcours ou encore la formation.

  • Dans votre fichier Excel (.xlsx) Scodoc, il est possible de lister les codes nip des étudiants démissionnaires dans la première colonne du deuxième onglet.

    Le code nip est un code à huit chiffres unique à chaque étudiant. Ce code est dans la colonne "Numéro" dans le fichier de macro. Vous pouvez ajouter les colonnes de noms et prénoms pour vous aider, les ajouter ne nuira pas au fonctionnement de l'outil.

    Conformément à la procédure, ces étudiants verront la valeur "DEF" appliquée sur chaque UE et la note de barème mise à zéro.

  • Le logiciel génère un fichier Excel composé de deux onglets :

    1. Données pour Apogée : Contient l'ensemble des étudiants trouvés à la fois dans le fichier .TXT et le fichier Excel exporté depuis Scodoc dans une version adaptée pour le fichier macro d'Apogée
    2. Etudiants non trouvés : Contient l'ensemble des étudiants dont le code nip n'est pas présent dans le fichier .TXT

    La source de vérité est le document .TXT qui contient les codes nip des étudiants. Si un des codes n'est pas présent dans le document Excel de Scodoc, alors ces étudiants seront dans l'onglet "Etudiants non trouvés".
